Chargement…
Version de développement. Le TinyRail View n'a pas encore été éprouvé sur du matériel. Ce firmware sert aux essais, pas à un van en service.
  1. Connectez le View en USB-C à votre ordinateur
  2. Cliquez sur Installer ci-dessous
  3. Sélectionnez le port USB dans le navigateur
  4. Ensuite, tout se règle depuis l'application mobile : appui long sur PWR, l'écran affiche un code à 6 chiffres à saisir dans l'app

Navigateur requis : Chrome ou Edge (Web Serial API)
