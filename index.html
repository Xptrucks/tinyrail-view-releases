Version de développement. Le TinyView tourne sur son écran, mais n'a pas encore été éprouvé avec une carte dans un van. Ce firmware sert aux essais, pas à un van en service.
  1. Connectez le View en USB-C à votre ordinateur
  2. Choisissez le lot de production, puis cliquez sur Flasher
  3. Sélectionnez le port USB dans le navigateur
  4. Ensuite, tout se règle depuis l'application mobile : ajoutez le View, son écran affiche un code à 6 chiffres à saisir dans l'app

Navigateur requis : Chrome ou Edge (Web Serial API)
